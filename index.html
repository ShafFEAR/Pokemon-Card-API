Pokemon Card Data API

A static mirror of the pokemontcg.io card database, served as plain JSON files from this repo via GitHub Pages. No rate limit, no API key needed to read it.

Loading dataset stats…

Endpoints

GET /data/sets/index.json      all sets
GET /data/sets/{setId}.json    one set + its cards, e.g. /data/sets/base1.json
GET /data/index/by-name.json   card name -> matching {id, number, setId, setName}[]

Example

fetch("./data/sets/base1.json")
  .then(r => r.json())
  .then(d => console.log(d.set.name, d.cards.length, "cards"));

Source, refresh script, and full docs: see the repo's README.
